This is the sixth requested EdgePress update for September 2026.

## Navigation and article reading

The shared navigation now includes a localized Posts link to the article archive. Markdown post pages generate a linked contents list from their headings.

## Code blocks and small screens

Generated code blocks now have an accessible copy button. Theme styles wrap long command lines so the full command remains readable on narrow screens without horizontal dragging. The theme development guide describes the shared behavior.

The project compatibility history is updated to version `2026.9.6`.

## Site identity and themes

The starter canonical URL is `https://edgepress.js.gripe` and the configured author is `toewpq`. The bundled themes have refreshed, higher-contrast palettes. The privacy policy continues to call for a real operator name and working privacy contact before publication.

## A clearer visual identity and reading path

The site now shares a local set of 22 SVG icons across theme navigation and feature cards. A page-shaped project mark, folded-paper sparrow mascot, and Open Graph image give the project a consistent preview on the homepage and when shared. Latest-post lists link into older archive pages, and localized post metadata now names each article's author.
