This is the fifth requested EdgePress update for September 2026.

## Clarify Cloudflare one-click deployment

The README and bilingual quick-start guides now explain that Cloudflare's Deploy button creates a new GitHub repository copy and a new Worker. Choose unused names for both during setup. The button does not connect to or update an existing Worker; use the existing repository's Workers Builds connection to publish updates.

The release notes and project compatibility history are updated as version `2026.9.5`.
